# 📚 Library Bot - Telegram Бот для обмена книгами

Полнофункциональный Telegram бот для управления библиотекой книг с пошаговыми визардами, бронированием и админ панелью.

---

## 🎯 Возможности

### Для всех пользователей:
- 📖 **Просмотр каталога** с фильтрами (все, доступные, по жанрам)
- 🔍 **Поиск книг** по названию и автору
- 🟢 **Бронирование** доступных книг с выбором срока
- 🔔 **Лист ожидания** для занятых книг
- 📚 **Мои книги** - управление своими книгами
- 🔙 **Возврат книги** с фото подтверждением (опционально)
- 📜 **История книги** - просмотр всех действий
- 🔔 **Push-уведомления** о статусе заявок, возвратах, напоминаниях

### Для администраторов:
- ➕ **Визард добавления книги** (6 шагов):
  1. Автор (с валидацией "два слова")
  2. Название
  3. Фото обложки (опционально)
  4. Описание и жанр
  5. Выбор владельца
  6. Подтверждение с превью
- ✅ **Подтверждение заявок** на бронирование
- ❌ **Отклонение заявок** с указанием причины
- 🗑 **Удаление книг**
- 📋 **Админ панель** с очередью заявок

## 🚀 Установка и запуск

### Шаг 1: Установка зависимостей

```bash
cd bot
pip install -r requirements.txt
```

### Шаг 2: Создание бота в Telegram

1. Откройте [@BotFather](https://t.me/BotFather)
2. Отправьте команду `/newbot`
3. Следуйте инструкциям
4. Скопируйте полученный **токен**

### Шаг 3: Настройка .env файла

```bash
# Создайте .env из примера
cp .env.example .env

# Отредактируйте .env
nano .env
```

**Обязательные параметры:**

```bash
# Токен бота от @BotFather
BOT_TOKEN=1234567890:ABCdefGHIjklMNOpqrsTUVwxyz

# URL вашего API (должен быть запущен)
API_URL=http://localhost:8000

# API токен (тот же, что в API .env)
API_TOKEN=ваш-секретный-токен

# Telegram ID админов (через запятую)
ADMIN_USER_IDS=123456789,987654321
```

**Опциональные:**

```bash
# Webhook для приема уведомлений от API
WEBHOOK_HOST=0.0.0.0
WEBHOOK_PORT=8001

# ID группы для уведомлений о новых книгах
GROUP_CHAT_ID=-1001234567890
```

**Как узнать Telegram ID:**
- Напишите [@userinfobot](https://t.me/userinfobot)
- Скопируйте ваш ID

**Как узнать ID группы:**
1. Добавьте [@userinfobot](https://t.me/userinfobot) в группу
2. Скопируйте ID группы (начинается с `-100`)

### Шаг 4: Проверка API

Убедитесь, что API запущен и доступен:

```bash
curl http://localhost:8000/health
```

Должен вернуть: `{"status": "ok", "service": "Library API"}`

### Шаг 5: Запуск бота

```bash
python main.py
```

Вы должны увидеть:
```
🚀 Bot started!
📡 Webhook listening on 0.0.0.0:8001
🔗 API endpoint: http://localhost:8000
👨‍💼 Admins: [123456789, 987654321]
```

## 🔄 Как работает бот

### Push-архитектура уведомлений:

```
API (Backend) ──[HTTP POST]──> Bot Webhook ──> Telegram User
```

1. API отправляет уведомления на `http://bot:8001/webhook`
2. Бот получает уведомление и отправляет сообщение пользователю
3. Никакой polling к API не требуется

### Типы уведомлений:

- ✅ **reservation_approved** - Бронь подтверждена админом
- ❌ **reservation_rejected** - Бронь отклонена
- 📚 **book_returned** - Книга возвращена
- 🔥 **waitlist_available** - Книга из waitlist освободилась
- 🚨 **overdue** - Книга просрочена
- ⏰ **due_date_reminder** - Напоминание о возврате
- 📖 **new_book** - Новая книга добавлена (в группу)
- 📩 **admin_reservation_request** - Новая заявка (админам)

## 🐛 Troubleshooting

### Проблема: Бот не запускается

```bash
# Проверьте токен
python -c "from config import settings; print(settings.bot_token)"

# Проверьте зависимости
pip install -r requirements.txt --upgrade
```

### Проблема: Бот не получает уведомления

1. Проверьте, что webhook запустился:
   ```bash
   curl http://localhost:8001/health
   ```

2. Проверьте настройки API (BOT_WEBHOOK_URL):
   ```bash
   # В API .env должно быть:
   BOT_WEBHOOK_URL=http://localhost:8001/webhook
   ```

3. Проверьте, что API_TOKEN совпадает в обоих .env файлах

### Проблема: "Invalid API token" при уведомлениях

API_TOKEN в bot/.env должен совпадать с API_TOKEN в api/.env

### Проблема: Админские функции недоступны

1. Проверьте ADMIN_USER_IDS в .env
2. Перезапустите бота
3. Отправьте `/start` заново

## 🔧 Разработка

### Добавление новых команд:

1. Создайте handler в `handlers/new_feature.py`
2. Зарегистрируйте router в `main.py`
3. Добавьте клавиатуры в `keyboards/inline.py`
4. При необходимости добавьте states в `states/wizard.py`

### Структура handler:

```python
from aiogram import Router, F
from aiogram.types import Message, CallbackQuery

router = Router()

@router.message(Command("mycommand"))
async def my_handler(message: Message):
    await message.answer("Hello!")
```
