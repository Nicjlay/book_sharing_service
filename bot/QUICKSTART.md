# 🚀 Быстрый старт - Library Telegram Bot

## 📋 Предварительные требования

✅ Python 3.11+
✅ API запущен и доступен на http://localhost:8000
✅ Telegram бот создан через @BotFather

---

## ⚡ 5 минут до запуска

### 1️⃣ Создайте Telegram бота (если еще нет)

```
1. Откройте @BotFather в Telegram
2. Отправьте: /newbot
3. Введите название: Library Bot
4. Введите username: library_exchange_bot
5. Скопируйте токен: 1234567890:ABCdef...
```

### 2️⃣ Узнайте ваш Telegram ID

```
1. Откройте @userinfobot
2. Скопируйте ваш ID (например: 123456789)
```

### 3️⃣ Установите зависимости

```bash
cd bot
pip install -r requirements.txt
```

### 4️⃣ Создайте .env файл

```bash
cp .env.example .env
nano .env
```

Минимальная настройка:

```bash
BOT_TOKEN=1234567890:ABCdefGHIjklMNOpqrsTUVwxyz  # от @BotFather
API_URL=http://localhost:8000
API_TOKEN=тот-же-токен-что-в-api  # из api/.env
ADMIN_USER_IDS=ваш-telegram-id
```

### 5️⃣ Запустите бота

```bash
python main.py
```

Должны увидеть:
```
🚀 Bot started!
📡 Webhook listening on 0.0.0.0:8001
🔗 API endpoint: http://localhost:8000
👨‍💼 Admins: [123456789]
```

## 🔧 Troubleshooting

### ❌ Ошибка: "Invalid token"

**Проблема:** Неправильный BOT_TOKEN

**Решение:**
```bash
# Проверьте токен в .env
cat .env | grep BOT_TOKEN

# Получите новый токен у @BotFather
# Отправьте: /token
```

### ❌ Ошибка: "Error connecting to API"

**Проблема:** API не запущен или недоступен

**Решение:**
```bash
# Проверьте, что API работает
curl http://localhost:8000/health

# Если не работает, запустите API:
cd ../api
uvicorn main:app --reload
```

### ❌ Ошибка: "Connection refused to localhost:8001"

**Проблема:** Порт 8001 занят

**Решение:**
```bash
# Измените порт в .env
WEBHOOK_PORT=8002

# Перезапустите бота
```

### ❌ Админские функции недоступны

**Проблема:** Ваш ID не в списке админов

**Решение:**
```bash
# Проверьте ADMIN_USER_IDS в .env
cat .env | grep ADMIN_USER_IDS

# Добавьте ваш ID
ADMIN_USER_IDS=ваш-id

# Перезапустите бота и отправьте /start заново
```

### ❌ Бот не отвечает

**Решение:**
```bash
# Проверьте логи в консоли
# Проверьте интернет соединение
# Проверьте, что бот не заблокирован у @BotFather

# Перезапустите:
Ctrl+C
python main.py
```

## 🎓 Дальнейшие шаги

### Добавьте других пользователей:

1. Попросите их запустить бота: `/start`
2. Они автоматически зарегистрируются

### Настройте группу (опционально):

1. Создайте группу в Telegram
2. Добавьте бота в группу
3. Добавьте @userinfobot в группу
4. Скопируйте ID группы (начинается с `-100`)
5. Добавьте в .env:
   ```bash
   GROUP_CHAT_ID=-1001234567890
   ```
6. Перезапустите бота

Теперь уведомления о новых книгах будут приходить в группу!

### Добавьте других админов:

```bash
# В .env добавьте их Telegram ID через запятую
ADMIN_USER_IDS=123456789,987654321,555555555
```

## 🐳 Docker Quick Start

### Вариант 1: Docker Compose (рекомендуется)

```bash
# В корне проекта (где есть и api и bot)
docker-compose up -d

# Проверка логов
docker-compose logs -f bot
```

### Вариант 2: Standalone Docker

```bash
cd bot

# Сборка
docker build -t library-bot .

# Запуск
docker run -d \
  --name library-bot \
  --env-file .env \
  -p 8001:8001 \
  library-bot

# Логи
docker logs -f library-bot
```
